# Guided Arrow v1.3.6

Compatible with Mount & Blade II: Bannerlord 1.3.15–1.4.7.

## Mission audio, penetration stability and Autoguidance

- Restores battle-command voices and normal mission audio by keeping the maintained sidecar off Bannerlord's native `Mission.*` collision and tick methods.
- Fixes protected-memory crashes during repeated terminal penetration continuations.
- Restores configured finite and infinite agent penetration across native `PassThrough`, `Stick` and `BecomeInvisible` reactions.
- Keeps shields, terrain, walls, trees and other world collisions terminal.
- Correlates simultaneous collision reactions with the exact owning projectile and protects concentrated split volleys from recycled missile indices and reaction-queue trimming.
- Preserves camera ownership through valid penetration chains and restores the native combat camera cleanly when the guided swarm ends.
- Repairs Autoguidance target state after impacts and continuation materialization without duplicate retarget passes.
- Creates generated split followers before manual guidance or Autoguidance initializes.
- Improves siege Autoguidance by leaving normal obstacle routing active while making the strict direct-line target filter optional and disabled by default.
- Moves Follow the Guided Projectile into Projectile Camera, Play Kill Cinematics into Kill Cinematic, and Visible Siege Targets Only into Autonomous Guidance on the main MCM page.
- Preserves values saved through the former Simple Controls page and hides that duplicate page.
- Verifies the maintained sidecar against Bannerlord 1.3.15 and 1.4.7 reference assemblies.
- Retains the byte-identical verified v1.1.17 gameplay core.

## Installation

1. Delete the existing `Modules/GuidedArrow` folder.
2. Extract the compiled ZIP into Bannerlord's `Modules` folder.
3. Enable Guided Arrow and its required dependencies in the launcher.

## Requirements

- Harmony
- ButterLib
- UIExtenderEx
- Mod Configuration Menu v5
